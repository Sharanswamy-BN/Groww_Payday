# Groww Payday

Clickable MVP: start a SIP on a debit date aligned with salary and bills.  
**Demo only** — no real UPI, mandate, or Groww account.

**Groq is not required.** Logic is rule-based.

## Run locally

1. Copy `.env.local` with `DATABASE_URL` (Neon).
2. `npm install`
3. `npm run dev`
4. Open http://localhost:3000
